# 확장 마켓플레이스

확장은 배포·설치의 상위 개념이며, 유형은 제공하는 내용으로 구분한다.

| 유형 | 제공하는 내용 | 설치·관리 대상 |
| --- | --- | --- |
| 스킬 | 에이전트의 지식과 작업 지침 | Claude Code·Codex의 스킬 폴더 |
| 워크플로 | 단계, 산출물, 승인과 전이 규칙 | 워크플로 라이브러리와 프로젝트 |
| 기능 | 화면, 액션, 외부 서비스 연결 | Sawhorse 앱과 프로젝트 |

한 패키지는 여러 유형을 제공할 수 있다. 설치된 v2 패키지에는 contributions에 따라 여러 유형을 표시한다. 워크플로 자체의 실행·승인 계약과 패키지의 권한·digest 검증은 그대로 유지한다.

확장 관리에는 설치됨·마켓플레이스·스킬·워크플로·기능을 둔다. 마켓플레이스는 탐색과 설치, 나머지는 설치된 항목의 관리다. 기능 탭에는 화면·액션을 제공하는 패키지와 기능 팩, 커넥터를 표시한다. 스킬 탭은 실제 에이전트 폴더의 스킬과 확장에 포함된 스킬을 관리한다.

## 기본 스킬 소스

`skills.sh`는 URL 등록 없이 사용할 수 있는 기본 소스다. 검색은 `https://skills.sh/api/search`에 보내며, 검색 결과의 `source`와 `skillId`로 다음 명령을 구성한다.

```text
npx -y skills add <owner/repo> -g -y --skill <skillId> --agent <agent>
npx -y skills update -g -y
```

앱의 `claude`는 CLI의 `claude-code`, `codex`는 `codex`로 매핑한다. 팩의 설치 지원 여부와 공개 스킬 CLI의 지원 여부는 별개다. 설치는 선택한 에이전트의 전역 범위다. 업데이트는 전역에 추적된 스킬 전체에 적용한다. 실행 옵션은 [공식 Skills CLI 문서](https://github.com/vercel-labs/skills)와 update 구현을 기준으로 한다.

검색 로딩·빈 결과·검색 오류·설치 오류·설치 완료·실행 로그를 각각 표시한다. 유형 필터를 바꿔도 검색 결과와 명시적으로 비운 대상 선택을 유지한다. 스킬 ID가 없는 응답은 설치 가능한 검색 결과에서 제외하며, 설치 API도 빈 스킬 ID를 거부한다. 응답 이상을 빈 검색 결과로 위장하지 않는다.

외부 Sawhorse 카탈로그와 로컬·HTTPS·Git 패키지는 별도 추가 설치 경로다. 공개 워크플로·기능 레지스트리를 임의로 가정하지 않고, 현재 패키지·내장 기능과 연결한 카탈로그를 보여준다.

브라우저 체험의 검색 결과는 `preview/agent-skills` 예제다. 실제 검색은 데스크톱에서 수행하고, 체험의 설치·업데이트는 데스크톱 필요 오류를 표시한다. 사용자 에이전트 폴더에 쓰지 않는다.

## 검증

- `bun run build`
- `bunx playwright test tests/extension-marketplace.spec.ts`
- `cargo test --lib skills_market::tests`

UI 검증은 기본 소스 검색, 대상 선택 유지, 설치 실패 후 재시도 가능 상태, 유형별 관리 이동, 두 화면 폭의 밝은·어두운 테마를 확인한다. Rust 검증은 응답 해석과 정확한 스킬·대상별 설치 인자를 확인한다. 실제 전역 스킬 설치·업데이트는 사용자 환경을 변경하므로 이 검증에서 실행하지 않는다.
