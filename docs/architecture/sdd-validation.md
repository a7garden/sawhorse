# SDD 작업대 검증 기록

2026-09-06, macOS 로컬 개발 환경에서 확인했다.

## 결과

| 검증 | 결과 | 범위 |
|---|---|---|
| Rust `cargo test --lib` | 217개 통과 | 기존 기능 및 SDD 저장소·하네스 |
| Playwright Chromium | 10개 통과 | 프로덕션 프론트엔드의 브라우저 체험 흐름 |
| Node 훅 테스트 | 27개 통과 | 기존 플러그인 훅 |
| TypeScript + Vite | 통과 | 타입 검사와 프로덕션 빌드 |
| Tauri macOS 앱 번들 | 생성 | 로컬 `.app`, 외부 배포 및 공증은 수행하지 않음 |
| SDD 스킬 형식 검사 | 통과 | `plugin/skills/sdd/SKILL.md` |

저장소 테스트는 스키마 버전, 잘못된 경로와 참조, 순환 의존성, 단계별 산출물과 검토 결정,
외부 파일 수정에 대한 revision 충돌을 검증한다. 하네스 테스트는 모의 Herdr CLI를 사용한
실행·출력·새로고침·소유 실행 중지, 실행 수 제한, 시작 중 취소, 재시작 복구, 하위 요청
중복 방지, 제어 키 제한, 동일 출력 중복 저장 방지를 검증한다.

브라우저 테스트는 프로젝트·작업 생성과 저장, 칸반 이동, 메타데이터 편집, 일정 생성·삭제,
Markdown 편집, 여러 탭의 저장 충돌, 미저장 문서 이탈 확인, 단계 검토 결정,
필터·검색 이동을 다룬다. 체험 모드에서 실제 에이전트를 시작하지 않는 동작과
데스크톱 오류를 예제 데이터로 숨기지 않는 동작도 확인한다.

화면은 1440px 기준의 작업대·칸반·캘린더·편집기와 밝은/어두운 테마를 확인했다.
브라우저 테스트는 Tauri IPC와 실제 사용자 볼트를 사용하는 종단간 테스트는 아니다.
개발 위임에는 설치된 Herdr와 실제 Codex 에이전트를 사용했으며,
완성 앱에서 사용자 프로젝트를 실행하는 통합 점검은 별도다.

## 처음 실행할 때

1. `app/src-tauri/target/release/bundle/macos/Sawhorse 작업대.app`을 연다.
2. 설정에서 작업공간 경로를 정하고 작업대의 **작업공간 초기화**를 실행한다.
3. **프로젝트**에 폴더와 에이전트 기본값을 등록한다. 설명·검증 명령은 저장 후 분석 에이전트가 채운다.
4. **새 작업**에서 의도를 작성하고 검토 결정을 남기며 다음 단계로 진행한다.
5. **에이전트 하네스**에서 실행·출력·승인 대기·후속 입력·하위 실행을 관리한다.

기존 사용자 볼트와 프로젝트에는 테스트 데이터를 쓰지 않았다. 초기화는 새 코어 폴더를
추가하며 기존 SI 폴더와 노트를 자동 변환하거나 삭제하지 않는다.

## 현재 운영 범위

- Claude Code와 Codex 실행에는 각 CLI의 설치와 로그인이 필요하다. 이 PC의 개발 위임은
  Claude 인증 만료로 Codex를 사용했다.
- Herdr 실행의 최대 동시 수는 기존 설정을 사용한다. 부모·자식 실행도 같은 제한을 받는다.
- 승인 대기 키와 후속 지시는 앱에서 사람이 명시적으로 보낸다. 대기 상태를 자동 승인하지 않는다.
- 앱이 닫혀도 Herdr 터미널은 유지된다. 상태 수집과 하위 요청 처리는 앱 실행 중 동작한다.
- 배포와 운영 모니터링은 프로젝트의 명령과 절차를 연결해야 한다. 릴리스 문서가 실제 배포를
  대신하거나 에이전트 종료가 검증 성공을 의미하지 않는다.
- 검색은 로컬 Markdown 정확 검색이다. zvec-grep 의미 검색은 아직 연결하지 않았다.
- 편집기 번들은 약 594KB로 Vite의 500KB 경고 기준을 넘는다. 별도 청크로 분리했으며 빌드는 통과한다.

재실행 명령은 [앱 개발 안내](../../app/README.md)에 있다.
