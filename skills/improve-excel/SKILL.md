# 개선 체크리스트 엑셀

`type: 개선` 노트를 발주처 보고용 엑셀 한 장으로 뽑는다.

정본은 **언제나 볼트 노트**다. 엑셀은 볼트에서 만들어지는 산출물이지 입력처가 아니다.
예외는 **요구자·담당자처럼 볼트에 없는 열** 하나뿐이고, 이건 엑셀이 정본이라 다시 뽑을 때 이어받는다.

## 실행

```
node ${CLAUDE_PLUGIN_ROOT}/skills/improve-excel/scripts/improve-xlsx.mjs \
  --out "<내보낼 경로>/개선수정사항-체크리스트.xlsx" \
  --prev "<직전에 보고한 xlsx>"
```

볼트 경로와 기본 사업은 `~/.claude/si-workbench/config.json` 에서 자동으로 읽는다. 다른 사업이면 `--project` 로 바꾼다.

`--prev` 는 **두 번째 회차부터 반드시 붙인다.** 빠뜨리면 지난 회차에 손으로 채운 담당자·요구자가 날아간다.
스크립트는 몇 칸을 이어받았고 어떤 칸이 비었는지 보고한다. **그 보고를 사용자에게 그대로 전한다.**

| 옵션 | 설명 |
|---|---|
| `--vault <경로>` | 생략하면 config 의 `vaultPath` |
| `--project <이름>` | 생략하면 config 의 `improve.defaultProject`, 그것도 없으면 사업 전체 |
| `--out <경로>` | 만들 xlsx (필수) |
| `--prev <경로>` | 직전 회차 xlsx — 수기 열을 이어받는다 |
| `--owner <이름>` | 담당자 기본값 (`--prev` 에 값이 없는 행에만) |
| `--org <이름>` | 요구기관 고정값 (기본은 `origin` 에서 파생) |
| `--title <문자열>` | A1 제목 |
| `--status <목록>` | `구현완료,승인대기` 처럼 status 로 거른다 |
| `--no-images` | 「근거이미지」 시트를 뺀다 (파일이 무거울 때) |
| `--max-image-w <px>` | 이미지 최대 가로. 기본 860 |
| `--json <경로>` | 행 데이터를 JSON 으로도 떨군다 (점검용) |

## 만들어지는 것

**시트1 「수정보완_체크리스트」** — 14열 + 숨긴 ID 열(O).

| 열 | 값이 어디서 오는가 |
|---|---|
| A No | 순번 (ID 오름차순) |
| B 접수일 | `raised` |
| C 요구기관 | `origin` 에서 파생 — 사용자 제안→내부리뷰 / 인수인계→인수인계 / 점검 발견→내부점검 |
| D 요구자 | **엑셀 전용** (연노랑 칸) |
| E 화면 명 | `screen` → 없으면 `url` |
| F 항목 | `item` |
| G 개선요구사항 및 오류사항 | 노트 제목에서 ID 접두사를 뗀 것 |
| H 검토결과 | `category` 에서 파생 — 버그→오류수정 / UI 개선·성능→개선요청 / 그 외→기타 |
| I 조치내용 | `action` (신규 / 수정 / 기존) |
| J 완료일(예정일) | `due` |
| K 우선순위 | `priority` 에서 파생 — 최우선→상 / 중요→중 / 보통→하 |
| L 완료여부 | `status` 에서 파생 — 구현완료→완료 / 구현중·부분구현→진행 / 보류→보류 / 반려→반려 / 나머지→대기 |
| M 담당자 | **엑셀 전용** (연노랑 칸) |
| N 비고 | `remark` |
| O FDR | 노트의 `id`. **숨김 열이고 동기화 매칭 키다 — 지우면 안 된다** |

**시트2 「근거이미지」** — 노트 본문의 `![[…png]]` 임베드를 문제별로 모아 붙인다.
시트1 G열 파란 글씨를 누르면 해당 위치로 뛰고, 시트2 소제목을 누르면 목록으로 돌아온다.
목업이 HTML 로만 있고 PNG 캡처가 없으면 그 문제는 시트2에 안 나온다.

## 동기화 규칙

1. 매칭은 **숨긴 O열의 ID** 로만 한다. 행 순서나 No 는 매칭에 쓰지 않는다.
2. **엑셀이 정본인 열** (요구자·담당자, 사용자가 직접 덧붙인 열) — 기존 값을 무조건 이어받는다.
3. **볼트가 정본인 열** — 볼트 값으로 덮어쓴다. 단 볼트 값이 비어 있고 엑셀에 값이 있으면 유실하지 않고 이어받고, **그 사실을 사용자에게 알린다** (볼트 노트에 넣어 둘 값이라는 뜻이므로).
4. 엑셀에서 지운 행은 다시 살아난다. 보고에서 빼려면 `--status` 로 거르거나 볼트에서 상태를 바꾼다.

## 금지사항

| 금지 | 대안 |
|---|---|
| 볼트를 안 고치고 **엑셀에 직접 값을 써넣기** | 노트 프로퍼티를 고치고 다시 뽑는다. 다음 회차에 덮여 사라진다 |
| 두 번째 회차부터 `--prev` 없이 실행 | 항상 붙인다. 못 붙였으면 그 사실을 반드시 말한다 |
| 숨긴 O열을 지우거나 열 순서를 바꾸기 | 매칭이 깨진다. 열을 늘리려면 N열 오른쪽에 덧붙인다 (그 열은 그대로 보존된다) |
| 비어 있는 칸을 임의로 지어내 채우기 | 보고에 그대로 올리고 사용자에게 무엇이 비었는지 알린다 |

## 구성

의존성이 없다. `node` 만 있으면 된다 (이 환경에는 Python 이 없어 openpyxl 계열을 못 쓴다).

- `scripts/improve-xlsx.mjs` — 본체. 볼트 읽기 → 행 만들기 → 엑셀 쓰기
- `scripts/xlsx-write.mjs` — 최소 XLSX 작성기 (zip + 시트 XML + 이미지 drawing + 서식)
- `scripts/xlsx-read.mjs` — 최소 XLSX 읽기 (`--prev` 용, 서식은 안 읽는다)
