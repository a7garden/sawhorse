# daily-log — 업무일지 작성

오늘의 세션 저널을 분석해 일지 노트의 `## 업무기록` 섹션을 작성한다. 호출: `/si-workbench:daily-log [$ARGUMENTS]`. `$ARGUMENTS`에는 세션에 남지 않은 구두 업무(회의 등)를 적는다.

## 공통 원칙

- 코드베이스는 읽기 전용으로만 다룬다. 어떤 저장소의 파일도 수정/삭제하지 않는다.
- **사용자가 쓴 글은 지우지 않는다.** 일지 노트의 어떤 섹션에서든 사람이 손으로 적은 문장을 삭제·요약 대체하지 않는다. 자세한 계약은 아래 [PRESERVE].
- 원격 저장소 변경 주의: `git push`, `svn commit`/`svn ci`, `git svn dcommit`, `hg push`는 불필요하면 실행하지 않는다. 로컬 `git commit`은 자유이며, 훅(block-push.ps1)이 원격 변경은 실행 전 사용자 확인을 요구한다.
- 위키 규범은 si-workbench:wiki를 준수한다. 일지 본문에서 개념이 처음 등장하면 `[[개념명]]`으로 링크하고, 개념 노트가 없으면 템플릿(`템플릿/개념.md`) 내용으로 생성한다. 죽은 링크 금지.
- 프로퍼티 키는 영어, 값은 한국어. 스키마는 design.md 표 그대로이며 스킬이 임의 필드를 만들지 않는다.
- vault 경로 결정: `${user_config.vault_path}` → `%USERPROFILE%\.claude\si-workbench\config.json`의 `vaultPath` → 사용자에게 절대경로 문의. 순서대로 시도한다.

## 분석 절차 (daily-report와 공통)

1. **저널 로드** — `%USERPROFILE%\.claude\si-workbench\journal\<오늘>.jsonl`을 읽는다. `<오늘>`은 로컬 날짜 `YYYY-MM-DD`. 라인 스키마: `{"ts","session_id","cwd","transcript_path","reason"}`.
2. **session_id dedup** — 같은 session_id가 여러 줄이면 마지막 것만 유효로 삼는다.
3. **transcript 샘플링** — 유효 라인의 `transcript_path`마다 다음 규칙을 그대로 적용한다:

[SAMPLING] transcript JSONL 샘플링 규칙: (1) 전체 통독 금지. (2) 먼저 라인 수 파악. (3) `"type":"summary"` 라인과 user 발화(`message.role == "user"`이고 content가 문자열이거나 content[].type=="text")를 추출. (4) 마지막 assistant 텍스트 1-2개만 추가. (5) tool_result 본문은 읽지 않는다. 파일이 크면 앞부분 user 발화와 뒷부분 마무리를 우선.

4. **프로젝트별 재구성** — `cwd`를 기준으로 작업을 프로젝트별로 묶고, `ts` 순서(시간순)로 작업 항목을 재구성한다.
5. **$ARGUMENTS 반영** — `$ARGUMENTS`(구두 업무: 회의 등)가 있으면 분석 결과에 추가 업무로 반영한다.
6. **세션이 없는 날** — 저널 파일이 없거나 유효한 세션이 없으면 빈 결과를 보고하고, `$ARGUMENTS`만으로 작성을 진행한다. `$ARGUMENTS`도 없으면 기록할 근거가 없음을 사용자에게 안내한다. 단, 기존 `## 업무기록`에 사용자 수기 기록이 남아 있으면 [PRESERVE] 재가공만 수행하고 종료한다 — 근거가 없다고 해서 노트를 비우지 않는다.

## 일지 노트 작성

[SECTION] 일지 노트 = `${user_config.vault_path}/일지/YYYY-MM-DD.md`. 노트가 없으면 템플릿(`템플릿/일지.md`) 내용으로 생성. `## 업무기록` 헤딩이 없으면 문서 끝에 헤딩과 자동 영역 마커를 함께 추가. `## 업무기록`의 갱신은 아래 [PRESERVE] 계약을 반드시 따른다.

[PRESERVE] `## 업무기록` 갱신 계약 — **사용자가 쓴 문장은 어떤 경우에도 사라지지 않는다.**

1. **먼저 읽는다.** 쓰기 전에 `## 업무기록` 헤딩 아래부터 다음 `## ` 헤딩(또는 EOF) 직전까지를 통째로 읽는다. 읽지 않은 채 쓰기 도구를 호출하지 않는다. `## 비고`, `## 내일 할 일`도 함께 읽어 중복 여부를 판단할 근거로 삼는다.
2. **백업.** 노트를 수정하기 전에 원본 전체를 `%USERPROFILE%\.claude\si-workbench\backup\일지-<YYYY-MM-DD>-<HHmmss>.md`로 복사한다(폴더 없으면 생성). 복사에 실패하면 노트를 수정하지 말고 사유를 보고하고 종료한다.
3. **영역 구분.** `<!-- si-workbench:auto:start -->`와 `<!-- si-workbench:auto:end -->` 사이는 지난 실행이 생성한 자동 영역이며 통째로 교체해도 된다(재실행 멱등). 마커 밖의 모든 텍스트(안내 주석 제외)는 사용자 수기 기록이며 교체 금지. 마커가 하나라도 없으면 **섹션 전체를 사용자 수기 기록으로 간주**하고, 마커를 새로 만들어 자동 영역을 구성한다.
4. **수기 기록 재가공.** 마커 밖 수기 기록을 덩어리(문단) 단위로 읽고 성격에 따라 배치한다. 원문의 고유 정보(수치, 고유명사, 사람 이름, 주소, 사용자의 판단)는 표현을 바꾸지 말고 살린다.
   - **오늘 실제로 한 일** → 자동 영역의 해당 프로젝트/시간 블록에 사실로 통합한다. 세션 근거와 겹치면 사용자 문장의 정보를 우선해 보강한다.
   - **앞으로 할 일·해야 할 것("~할 것", "~필요")** → `## 내일 할 일`에 `- [ ]`로 추가한다. 완전히 동일한 문구가 이미 있으면 추가하지 않는다.
   - **개념·용어·시스템 구조 설명** → si-workbench:wiki 규범대로 개념 노트로 옮기고, 업무기록에는 `[[개념명]]` 링크와 한 줄 요약만 남긴다.
   - **특정 사업/개선 문서에 속하는 상세** → 해당 노트에 추가하고 일지에는 링크만 남긴다.
   - **그 외 메모(연락처, IP·경로, 잡기)** → `## 비고` 끝에 덧붙인다.
   - **분류가 애매하면 옮기지 않는다.** 원문을 `## 업무기록`의 자동 영역 **바깥**에 그대로 두고, 보고에 "미분류로 보존"이라 적는다. 판단이 서지 않을 때의 기본값은 항상 원문 보존이다.
5. **중복 처리.** 원본에서 문장을 제거해도 되는 경우는 **완전히 동일한 문장이 옮겨간 대상 섹션에 이미 존재할 때뿐**이다. 요약·의역으로 원문을 대체하지 않는다.
6. **다른 섹션 수정 범위.** `## 비고`와 `## 내일 할 일`은 4단계의 이관을 위해 **덧붙이기만** 한다(기존 줄 삭제·수정 금지). `## 오늘 할 일`은 daily-log가 건드리지 않는다.
7. **이관 보고 필수.** 재가공한 덩어리마다 `원문 첫 문장(20자) → 옮긴 위치`를 표로 보고한다. 옮긴 위치가 없는 원문이 하나라도 있으면 작업이 잘못된 것이다.

기록 작성 규칙(자동 영역 본문):

- 시간순 프로젝트/작업 블록으로 구성한다. 블록과 항목의 순서는 실제 작업 시간 순서를 따른다.
- 각 항목에는 무엇을 했는지, 왜 했는지, 결과(남은 것이 있으면 그것까지)를 담는다.
- 한국어 완결 문장으로 쓴다. 명사 나열·조사 생략 금지.
- 개념 첫 등장 시 `[[개념명]]` 위키링크(노트 없으면 템플릿으로 생성 — 죽은 링크 금지).
- 노트 생성 시 템플릿의 frontmatter(`type: 일지`, `tags`)를 그대로 유지하고 임의 필드를 추가하지 않는다.

## 완료 후 보고

작성이 끝나면 다음을 보고한다:

- 노트를 신규 생성했는지, 기존 자동 영역을 교체했는지, 백업 파일 경로
- 반영한 세션 수와 프로젝트(cwd) 수, `$ARGUMENTS` 반영 내역
- [PRESERVE] 7단계 이관 표 — 수기 기록이 있었다면 각 덩어리가 어디로 갔는지. 수기 기록이 없었으면 "수기 기록 없음"이라고 명시한다.

## 금지

- `## 업무기록`의 수기 기록을 읽지 않고 덮어쓰기.
- 백업 없이 노트 수정.
- 사용자 문장을 요약문으로 대체하거나, 중복이 아닌데 삭제하기.
- `## 비고`·`## 내일 할 일`의 기존 줄 수정·삭제.
